# HSJY App

> 红色教育 Web 应用。

[English](./README.md) | [简体中文](./README.zh-CN.md)

## 项目简介

HSJY App 是一个基于 Vue 的红色教育类 Web 应用，包含新闻、知识页面和用户中心等功能。

## 快速开始

### 克隆项目

```bash
git clone git@gitee.com:patrick12138/hsjy-app.git
cd hsjy-app
```

### 安装依赖

使用 npm：

```bash
# 如果 npm 下载较慢，可使用镜像源
npm install --registry=https://registry.npmmirror.com
```

使用 yarn：

```bash
yarn install
```

### 启动开发环境

使用 npm：

```bash
npm run serve
```

使用 yarn：

```bash
yarn serve
```

## 构建生产版本

```bash
npm run build
```
